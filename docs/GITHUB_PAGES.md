# Publish the website

1. Push the project contents, with index.html at the repository root.
2. Open GitHub repository Settings → Pages.
3. Select Deploy from a branch, main, /(root), then Save.
4. Use the website URL shown in Pages once deployment succeeds.
5. On the repository home, edit About (gear), paste this URL in Website, and Save.

Source: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
